This directory is a code-only snapshot prepared from the shared MyGram Drive folder.

Verified source SHA-256: `b63ecc0c50f1ac2aba923355f8015eacf1b3e47c1a13b9d7d34662f0ac66fc35`

## Required execution inputs

- `src/`: model, graph, loss, training, evaluation, iterative learning, checkpoint, artifact-store, configuration, and data-registry code.
- `scripts/`: Colab bootstrap, data preparation and validation, gate runners, experiment-matrix runner, environment checks, and artifact synchronization.
- `configs/`: repaired PMF profile, author-compatibility profile, smoke configuration, and the 38-run experiment matrix.
- `requirements/` and `requirements.in`: Colab and local dependency locks.
- `notebooks/MyGram_Colab.ipynb`: base Colab workflow.
- `notebooks/table_runs/MyGram_Table1_RunAll.ipynb`: Run All workflow for the six Table 1 experiments and report generation.
- `notebooks/table_runs/MyGram_Table2_RunAll.ipynb`: Run All workflow for the three Table 2 experiments and report generation without removing Table 1 data.
- `tests/`: unit and gate tests for data, sparse graph, losses, checkpoint/resume, evaluation, iterative learning, matrix completeness, and Colab portability.

## Refactor and provenance context

- `plan_pipeline.md`: authoritative staged reproduction plan.
- `chuyen_sang_colab.md`: Colab migration plan.
- `README.md` and `docs/implementation_decisions.md`: current structure and implementation decisions.
- `provenance/source_bundle_manifest.json`: original Drive bundle manifest and file hashes.

## Deliberately excluded

- Dataset archives and extracted datasets.
- Checkpoints (`last.pt`, previous checkpoints), predictions, logs, and run snapshots.
- Generated Table 1/Table 2 CSV/PNG/PDF/ZIP reports.
- Historical Stage A–F reports and `environment.json` generated by prior checks.
- W&B upload/report notebooks, because they are downstream reporting tools and are not required to train or build Table 1–2.
- `mygram.pdf`, `MyGram.jpg`, audit dumps, and the upstream `pmf_mmkg.zip` archive.

These exclusions keep the refactor input small and prevent research outputs or large binary data from being mixed into the source repository. Existing results remain on Drive and are not modified by this snapshot.
